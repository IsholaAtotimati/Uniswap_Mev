# MEVShield Risk Engine

Off-chain adaptive risk engine powering the MEVShield Uniswap v4 Hook.

## Features

- Feature extraction
- Sandwich detection
- Toxic flow analysis
- Arbitrage detection
- Wallet profiling
- Dynamic fee recommendation
- EIP-712 payload signing
- EigenLayer AVS ready

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Docker

```bash
docker compose up --build
```
